# Lumber Assist

Minecraft 26.2 (Fabric) 자동 벌목 모드 — Made by seolwoni

- 도끼를 들고 구역의 두 모서리를 Shift + 우클릭해서 구역 지정 (여러 개 가능, 설정에서 목록 관리)
- 구역 안의 나무를 통째로 베기: 참나무, 가문비, 자작, 정글, 아카시아, 짙은 참나무, 맹그로브, 벚나무, 창백한 참나무 (2×2 나무 포함)
- 높은 나무는 발밑에 흙·돌을 쌓고 올라가서 베고, 쌓은 블록을 캐면서 내려와요
- 묘목 다시 심기, 떨어진 묘목·사과 줍기, 묘목은 종류별로 남기고 모자라면 상자에서 가져오기
- 한 바퀴 돌고 보관 → 5분 대기 → 반복
- 상자 여러 개(최대 10개, K로 지정) 분류 보관, 사람 같은 움직임, 자동 밥, 안전장치, 상태·벌목 통계 HUD
- Assist Core 포함 (H키로 모든 Assist HUD 숨기기)
